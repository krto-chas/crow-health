# Status

## Present in this package
- EvidenceFile, ImportJob and Observation models.
- Immutable ZIP archiving with SHA-256 manifest.
- ZIP inventory and JSON structural profiling.
- Parser protocol and four initial contracts.
- Automated tests.

## Not present
- Garmin health-data parsers.
- Normalized health database.
- Analytics, predictions, AI, API, dashboard or Home Assistant integration.

## Verification boundary
Linux verification is recorded in `VERIFICATION.txt`. Windows verification must be performed by the user after installation.
